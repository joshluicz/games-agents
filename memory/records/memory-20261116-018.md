# A Nurse Agency (5-min restock), a same-server Player Market, and roster caps

**Joshua, 2026-11-16 (chat), verbatim:**
> then he suggested that there can be a market for nurses too. im questioning if it makes the conveyor belt redundant.
> but the shop would be a global server stock that refreshes every period like 5min.
> and players can sell their nurses in there and others can buy...
> but obviously now we need caps for the number of nurses.

## What this rules (design §8 of `docs/plan/2026-11-16-depth-update-design.md`)
1. **The belt stays:** random, a race, and the only source of Legendary and above. It's not redundant.
2. **The Nurse Agency:** a server-wide restock every 5 min; 4 nurses, Common to Epic; each player can buy each once;
   sell-back for about 30%.
3. **The Player Market:** same server only; listings within a price band; instant buy; a 10% fee; no swaps or
   haggling; listings end when the seller leaves; atomic transfers; no Robux. These are kids' anti-scam and anti-dupe
   rules.
4. **Caps:** a roster of 30, +5 per hospital level, +10 per rebirth, up to 100; equipped slots 1–5 (+1 from the
   tree). The Journal keeps history after selling.
