3. **A group later is possible.** Creator Hub supports moving an experience from a user to a group the user can

   group back to a user isn't supported, so it's one-way. Do it at a quiet time, before passes multiply.
   Source: https://create.roblox.com/docs/projects/experience-ownership-transfer (searched 2026-11-16).
