# Soft return pressure is OK; admin abuse events must come

**Joshua, 2026-11-16 (chat), verbatim:**
> yes it should have some soft pressure for them to want to come. admin abuse is something my brother loves and says
> that we MUST implement in the future. its one of the best hooks.

This was his reply to Claude saying it wouldn't copy a reference game's "Like & favorite = admin abuse" sign or its
"Next update" countdown.

## What it decides
1. **Soft return pressure is wanted.**
   - A countdown or a "next event" sign for a **free** upcoming event is allowed: Golden Hour, Night Rush, the next
     admin event, the next update.
   - This overrules Claude's calls in `-020` §2 (Golden Hour never shows a countdown) and `-021` #3 (no clocks).
2. **Admin abuse events are a must, in a future update.**
   - A scheduled live event where the brothers join and use fun server-wide powers for everyone.
   - The brother asked for it. When it ships, who hosts and how often are OPEN #9.

## What it doesn't change (red line 3, Claude's reading)
- **Nothing pressures spending.** No timer on a Robux offer, no "only N left" on anything paid, no paid item tied to a
  countdown.
- **Roblox's rules as they read today decide the details.** Before building "like & favorite for a reward" or any
  event announcement, check the live Terms of Use and Community Standards (research in
  `docs/research/2026-11-16-admin-abuse-and-return-hooks.md`).
- **An event announced for a time has to happen.** A real admin event needs one of the brothers online. Hours are
  `../joshua-hq`'s call (red line 6).
