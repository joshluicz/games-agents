# Joshua builds alone; the old Shop is gone; the look goes saturated and flashy

**Joshua, 2026-11-16 (chat), verbatim:**
> Okay, my brother won't be doing much. Now it's really just on me. So let's see if we can tidy up and do more stuff
> on our end. Delete the old shop model for me, and then after that, for the color wise, I think we can use more
> colors. Like if I recall properly, the colors used on these trending games are more saturated rather than what we
> have now. [...] All the UIs that are in the trending games have these like really flashy UI, and colors as well. So
> like a big color revamp [...] and I think the textures and all can be even more trendy.

## What this rules
1. **Joshua builds the game, world included, with Claude.** The brother's kit (`docs/guides/build-the-clinic.md`)
   is optional now: the code's own placeholders are the real look until something replaces them. The brother's
   other roles in `context/team.md` stand unless Joshua says otherwise.
2. **`Workspace.Shop` is deleted** (saved as place version 16; version 15 still has it) and so is `RoofFade.client.luau`.
3. **The look is saturated and flashy.** This replaces design §6's "cozy and bright, not oversaturated".
   Claude's specifics ("candy pop", `game/src/shared/Palette.luau`): full-saturation candy colours, thick dark
   outlines (`Palette.Outline`), chunky outlined display text (LuckiestGuy), glossy gradient buttons with a shine on
   calls to action, reward rays, and a toy-like world (SmoothPlastic, a little Neon, no realistic materials).

## Still holding (red line 3)
Flashy, not pushy: no flashing at strobe rates, every motion honours Reduced Motion and the in-game calm toggle,
and nothing flashy points at spending.
